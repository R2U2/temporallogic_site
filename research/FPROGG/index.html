FPROGG: A Formula Progression-Based MLTL Benchmark Generator

Alec Rosentrater, Kristin Yvonne Rozier, and Phillip Jones

This webpage contains further details and artifacts for reproducibility of the experiments in "FPROGG: A Formula Progression-Based MLTL Benchmark Generator"

Abstract

Mission-time Linear Temporal Logic (MLTL) is a popular variant of Linear Temporal Logic with closed interval integer bounds, evaluated over finite traces. There is a growing number of tools that reason over MLTL (e.g., for runtime verification, model checking, or specification elicitation), however there is a lack of benchmarks for comparing their performance, and testsuites for validating them. An MLTL benchmark is a three-tuple consisting of a formula; a trace of variable assignments over time; and a sequence of verdict-timestep pairs indicating at each trace timestep whether the formula evaluates to true or false. We introduce the open-source Formula PROGression Generator (FPROGG) tool to construct MLTL benchmarks through formula progression. FPROGG takes a formula, a desired satisfiability pattern, and a desired trace length as input and returns an MLTL benchmark instance. We contribute an extensible tool implementation, argue for its correctness, and collect a varied set of 200,000 pre-computed MLTL benchmarks of trace length 100 for use by the research community.
