Model Predictive Runtime Verification for Embedded Platforms with Real-Time Deadlines

Pei Zhang, Rohit Dureja, Matthew Cauwels, Joseph Zambreno, Phillip H. Jones, Kristin Yvonne Rozier

This webpage contains further details and artifacts for reproducibility of the experiments in "Model Predictive Runtime Verification for Embedded Platforms with Real-Time Deadlines"

**The full version of the paper is available here (pdf)**

Abstract

Reactive systems require mission-time verification that accurately captures future-time requirements. On-board runtime verification (RV) requires real-time responsiveness that can be embedded within the limited resources (timing, power, weight, bandwidth, hardware, etc.) of the running system. For effective mitigation triggering, RV must detect faults as-early-as-possible, plus make best-possible predictions of future faults on-deadline. Effective on-board RV will always need to know or predict whether, e.g., the parachute needs to be deployed by the deadline for it to be effective (e.g., to cushion the aircraft's landing). To maximize accuracy and reduce mission-ending mistakes, RV must use real data whenever possible. We contribute a formal definition of real-time Model Predictive Runtime Verification (MPRV) that uniquely uses real data wherever possible, predicting only the minimum variable values required to make an on-deadline, best-as-possible requirement evaluation. MPRV carries a design-time model to runtime to fill in individual predictive values only when necessary. We devise a generic algorithm for MPRV on embedded platforms with limited resources, proving the worst-case execution time and memory usage. We contribute a specialized algorithm for implementing MPRV in FPGA hardware and argue for its correctness. We implement MPRV as a significant extension to the R2U2 RV engine, release a new version of that tool, and conduct an extensive experimental analysis demonstrating its utility and performance.
