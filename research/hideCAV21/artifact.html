Simulation of MPRV for UAV

Experiment steps in VM (download here with username: NODE, password: node):

1. Do the simulation of controlling a UAV to follow a trajectory. This generates the desired trajectory and the control trajectory. It also prodeces the predicted trajectory at each time stamp.

2. Run the simulation of Predictive RV for MLTL formula "G[5] a0".

3. Run the simulation of Predictive RV for MLTL formula "a1".

4. Run the simulation of Predictive RV for MLTL formula "(G[5] a0) U[10] a1" with prediction step Hp=5.

5. Run the simulation of Predictive RV for MLTL formula "(G[5] a0) U[10] a1" with prediction step Hp=20.

6. Plot the UAV control and MPRV result figure.

Press run command in the VM:

cd ~/Document/exp_UAV; ./autoRun

(MPRV code in VM: ~/Document/exp_UAV/ACOW/)

Hardware resource usage:

The hardware resource usage is reported by the Vivado 2019.2. We also collected the result in our python script for plotting.

To visually see the resource utilization, run command:

cd ~/Document/fpga_resource_usage; ./python rv_mpc.py

The result for estimating the scability of MPC is generated by the following command:

cd ~/Document/exp_UAV/admm_time_resource; ./python time_and_resource.py
